# Drop the powder-room photos here

This folder exists so the photos have somewhere to go. Upload them straight into
it on GitHub: **Add file → Upload files**, drag them in, Commit.

Any filenames are fine. The names below are what `assets/site.config.js` currently
expects, but they are easy to change and renaming them is a one-minute job:

| Expected filename | Photo |
|---|---|
| `powder-vanity-wide.jpg`   | Vanity with the oval brass mirror and walnut cabinet |
| `powder-swan-corner.jpg`   | Corner with the swan painting and the horse print |
| `powder-full-room.jpg`     | Whole room, wide, showing the rug |
| `powder-from-door.jpg`     | Looking in from the doorway |
| `powder-shower-side.jpg`   | Glass shower enclosure at the left |
| `powder-toilet-wall.jpg`   | Toilet wall with the artwork above the wainscot |

Once the files are in, delete `pending: true` from the matching six lines in
`assets/site.config.js` and they appear in the gallery. Alt text is already written
for each one.

Send the largest version you have. Everything currently on the site is a frame
pulled from compressed video, so these will be a visible upgrade.

This README can be deleted once the photos are in.
